# 鱼鱼人格配置包 · 第一阶段

**v0.2.1｜人格与文字聊天**

先把 QQ 里的鱼鱼聊起来：温和搭子的人格、自然的说话方式、分段回复和模拟打字等待。

使用前，你的 AstrBot、QQ 连接和对话模型应已经可用，发普通消息能够收到回复。本包负责后续的人格与聊天节奏配置。第一阶段不包含图片、表情插件、语音、主动聊天或长期记忆；后续可按篇章添加。

## 到 Windows 上先这样做

1. 解压整个文件夹。打开实际 AstrBot 后台，复制地址栏中的协议、主机和端口；Launcher 的端口以当前实例为准。再给 QQ 机器人发一句话，确认原连接能聊天。
2. 在你要测试的 QQ 私聊发 `/sid`，复制完整会话标识，例如 `平台ID:FriendMessage:会话ID`。
3. 双击 **导入鱼鱼.bat**，输入后台地址、账号密码、完整会话标识，查看范围后输入“导入”。密码输入时不显示。
4. 双击 **检查鱼鱼.bat**，使用相同后台地址和会话标识。配置回读通过后，按 [安装后检查](docs/Windows验收.md) 在 QQ 里试聊。

运行工具需要 Python 3.10+。入口先寻找本机 Python 和 AstrBot Launcher 默认实例里的解释器，不会下载安装 Python。找不到时参照 [INSTALL.md](INSTALL.md)，也可以只用后台手动配置。

## 打字模拟是什么效果

两句话可以分两个气泡发送；每段发出前，根据内容长度等待，额外增加一点随机停顿。默认中文大约为：5 字等待 1.1–1.6 秒，15 字 1.7–2.2 秒，30 字 2.1–2.6 秒。这是模型生成完成后的附加等待，总响应时间还包含模型自身耗时。

实现用 AstrBot 自带的按长度发送间隔，默认 `interval_method=log`、`log_base=5.0`。它不在 QQ 上显示“正在输入”，不逐字编辑消息，也不会故意打错字。按换行分段；超过 150 字的长文本保留完整，避免把教程拆成很多气泡。模型只写一句时，只有一个气泡是正常现象。

## 安装会做什么

- 新增或复用内容相同的 `鱼鱼_温和搭子_v021` 人格。
- 复制目标会话原来使用的配置，建立一份专用配置；原配置保持原值。
- 在专用配置里开启按换行分段、按长度等待，并关闭流式输出、自动语音和文转图。
- 把该会话绑定到专用配置，并设置会话人格，避免已有对话的旧人格覆盖默认设置。
- 保存本轮恢复所需的小范围状态，重新读取设置检查是否一致。

不新增插件，不下载素材，不清空历史。模型和 QQ 连接仍由原有服务提供。已有第三方插件可能继续影响回复；首次使用请使用普通 AstrBot 内置执行器，并按安装后检查说明排查干扰。

## 交给 Agent 配置

Agent 必须能在运行 AstrBot 的电脑上读取文件、执行命令或操作后台。分享时使用固定版本 [v0.2.1](https://github.com/iohasfgioha/yuyu-persona-pack/tree/v0.2.1)，或下载 [v0.2.1 Release](https://github.com/iohasfgioha/yuyu-persona-pack/releases/tag/v0.2.1)，避免直接执行日后变化的 main。把下面这句话发给它：

> 我的 AstrBot、QQ 和对话模型已能正常聊天。请使用 https://github.com/iohasfgioha/yuyu-persona-pack/tree/v0.2.1 对应的固定版本，读取 README.md、INSTALL.md 和 AGENTS.md。先核对实际后台端口和 /sid 返回的完整会话标识，依次运行 check、inspect、plan，核对改动范围符合我的请求后配置鱼鱼人格、分段回复和打字等待。保留原连接和聊天记录，密码由我在本机隐藏输入或通过临时环境变量提供。完成后回读检查，给出 preview 改动摘要和实际 Git 提交号；使用 Release ZIP 时报告包版本及下载文件的 SHA-256。

[INSTALL.md](INSTALL.md) 提供可复制的 `inspect / plan / install / verify / restore` 命令。[AGENTS.md](AGENTS.md) 是支持该文件的 Agent 的入口，两份说明都在仓库根目录。

## 导入工具与回答文件

导入工具是实际执行配置的程序，负责创建人格、绑定会话、保存恢复记录和回读检查。

回答文件是它的“预填表格”，填实际后台地址、用户名、目标会话，以及临时密码环境变量的名称。人可以双击后逐项回答；Agent 用回答文件，减少交互中断。回答文件不会增加聊天能力，也不是 AstrBot 的整份配置。

第一阶段保留两种方式：普通使用者双击即可；Agent 可参照 `examples/answers.example.json`。密码正文不要放进回答文件或 GitHub。

## 恢复与后续修改

双击 **恢复鱼鱼设置.bat**，会恢复本轮改过的会话绑定和会话字段。后来手动改过同一项时会停止覆盖；后来新增的其他设置会保留。恢复不删除人格或专用配置，确认不再使用后可在后台删除。

人格可以在后台编辑，聊天节奏可以在鱼鱼专用配置中改。改过后再次导入会报告差异，避免悄悄覆盖你的调整。`verify` 显示差异表示偏离发行配置，并不意味着你的自定义本身有错。

`.local/` 包含会话标识与恢复状态，只留在使用者本机。分享源码或发行包时，用构建工具输出的 ZIP，不要重新压缩已使用过的整个文件夹。

使用时可从 [使用检查记录](docs/验收记录模板.md) 复制一份本地记录。发布步骤见 [GitHub 发布](docs/GitHub发布.md)，兼容范围见 [兼容与来源](docs/兼容与来源.md)。

## 使用与升级提示

- 默认只有真实出现过的 QQ 会话能安装；`plan` 返回 `umo_seen`。未找到时先发消息并重新复制 `/sid`。
- 改 README、翻译说明或缺少辅助文档只显示 `warnings`；执行脚本、配置和 `persona/yuyu.md` 仍做严格校验。修改人格后需重新构建；中文人格文件是阅读副本。
- 中文文件名解压异常时，使用 `install.bat`、`verify.bat`、`restore.bat`。
- 专用配置是导入时的副本。之后修改 `default` 不会自动同步到鱼鱼会话，需要在鱼鱼专用配置中调整。
- 装过 v0.1 或 v0.2.0 时先看 [旧版迁移](docs/旧版迁移.md)。`cleanup --legacy` 只列出旧设置，不自动停用或删除。
