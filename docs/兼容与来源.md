## 已知边界

- 仅支持在 AstrBot 同机访问 loopback 后台；远程服务器、反向代理子路径和云端 Agent 直连不在自动工具范围内。
- 不安装 AstrBot、QQ 连接程序、Python 或模型。使用者先完成基础连接。
- `plan`/`verify` 不向 QQ 发送测试消息，也不调用收费模型；它们不能证明人格实际输出质量。
- 不接管已有第三方插件、外部 Agent Runner 或消息后处理。它们可能覆盖人格、流式或发送节奏，需要实机排查。
- 原有模型权限与工具设置继承源环境；角色提示词不等于权限控制。
- 不实现跨版本自动迁移；恢复保留人格和新建的专用配置。它不是彻底卸载功能。
- 状态中的地址需保持一致，例如不要在同一轮安装/恢复间更换 localhost 与 127.0.0.1。
- 回复等待包含模型自身耗时；没有承诺 QQ 输入状态或精确固定秒数。

## 本地复核

普通逻辑与 HTTP 模拟检查：

```text
python -m unittest discover -s tests -v
```

官方源码对照检查还需将环境变量 `ASTRBOT_SOURCE` 指向上述固定提交的本地源码目录。没有提供源码时，4 项对照检查会明确显示跳过；不要把跳过算成通过。对照测试读取源码或提取独立函数，不启动完整 AstrBot。
